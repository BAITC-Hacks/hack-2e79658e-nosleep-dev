# Astana district geometry

`astana-districts.json` contains the five district boundary relations from
OpenStreetMap, retrieved through Nominatim on 2026-09-23. The geometry is
provided by OpenStreetMap contributors under the Open Database License (ODbL).
The play page displays the required attribution and links to
https://www.openstreetmap.org/copyright.

| District | OSM relation |
| --- | ---: |
| Есиль | 3479876 |
| Алматы | 3482819 |
| Сарыарка | 3486954 |
| Байконур | 8593081 |
| Нура | 20593940 |

Map tiles come directly from `tile.openstreetmap.org` when the play page is
open. The score indicators and population shares in `data/districts.json` are
game scenario inputs; the real geometry does not imply measured district
conditions.
